# ⚡ Electricity Consumption Forecasting System

An end-to-end time-series forecasting platform predicting hourly energy demand (in Megawatts) using XGBoost.

🚀 **Live Interactive App:** [EnergyAnalytics Dashboard](https://whuxt7shfvsitgugdzbb84.streamlit.app/)

## 📌 Key Features
- **Analytics Dashboard:** Real-time operational metrics, demand trends, and statistical distributions.
- **Data Explorer:** Interactive search, filtering, and CSV export for cleaned energy records.
- **Seasonal Analysis:** Hourly and monthly demand profiling.
- **Data Ingestion:** Upload custom energy dataset CSVs directly through the UI.
- **ML Load Predictor:** Hourly load forecasting powered by a trained XGBoost Regressor model.
